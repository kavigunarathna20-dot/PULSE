User Profile

Technical Description

HTML Structure The User Profile page was developed using semantic HTML elements including header, nav, main, section, and footer to create a clear and consistent page structure. The main element contains the profile-building interface and the profile display area. Separate sections were used to organise profile information into logical categories, improving readability and maintainability.

CSS Techniques CSS was used to create a clean and responsive layout that matches the visual identity of the website. Flexbox was used to organise profile cards and information panels efficiently across different screen sizes. Consistent colours, spacing, shadows, and border-radius properties were applied to improve visual appeal and usability. Progress indicators and profile sections were styled to provide clear visual feedback during profile completion.

JavaScript Interactivity JavaScript provides the main functionality of the page. The prompt() method was used to collect user information in multiple stages, following the coursework requirement for a step-by-step profile-building process. User data was stored using JavaScript objects and variables, allowing information to be updated dynamically. Functions were created to handle data collection, update profile information, calculate completion percentages, and render content to the page. DOM manipulation techniques such as getElementById() and innerHTML were used to display profile information without reloading the page. Conditional statements were used to manage skipped questions and update the completion progress correctly.

Design Decisions A progressive profile-building approach was chosen because it prevents users from becoming overwhelmed by large forms and creates a more interactive experience. The use of JavaScript prompts and dynamic content updates demonstrates effective use of client-side scripting while meeting the project requirements. The progress indicator was included to encourage users to complete their profiles and provide immediate feedback throughout the process.


Accessibility

The User Profile page was designed with accessibility in mind to ensure it can be used by a wide range of users. Semantic HTML elements such as header, main, and section provide meaningful structure for screen readers and assistive technologies. Clear headings and descriptive labels were used throughout the page to improve navigation and readability. A consistent colour scheme with sufficient contrast was selected to ensure that text remains easy to read. The page uses responsive design techniques so content can adapt to different screen sizes and devices. The profile completion progress indicator provides visual feedback that helps users understand their current progress. Instructions and feedback messages are written in simple, descriptive language to improve usability. Keyboard-accessible controls and logical content organisation further enhance the user experience for individuals who rely on assistive technologies.
