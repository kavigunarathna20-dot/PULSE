User Profile

Technical Description

The User Profile page was developed using semantic HTML elements such as header, main, section and footer to create a clear page structure. CSS Flexbox was used to organise profile information and create a responsive layout. JavaScript was used to collect user details through prompts, update profile information dynamically and calculate profile completion progress. DOM manipulation techniques were used to update content without reloading the page.

Accessibility

Semantic HTML elements provide meaningful structure for screen readers. Clear headings, sufficient colour contrast and responsive layouts improve accessibility across devices. Keyboard-accessible controls and descriptive text were used throughout the page.

Challenges & Lessons Learned

Responsive Layout Design

Creating a layout that displayed correctly across desktops, tablets and mobile devices was one of the main challenges during development.

Solution: CSS Grid, Flexbox and media queries were used to adapt the layout to different screen sizes.

Lesson Learned: Responsive design should be considered from the beginning of the design process rather than added later.

JavaScript Functionality

Implementing dynamic profile generation and progress tracking required careful organisation of JavaScript functions.

Solution: The code was divided into reusable functions to improve readability and maintainability.

Lesson Learned: Modular programming simplifies debugging and future updates.

Validation and Accessibility

Several HTML validation errors and accessibility concerns were identified during testing.

Solution: The W3C Validator was used regularly and accessibility guidelines were followed when creating page structures.

Lesson Learned: Regular testing and validation help maintain quality and standards compliance.

Compliance

The pages I developed were designed in accordance with recognised web publishing and accessibility principles. Semantic HTML elements such as header, nav, main and section were used to create a meaningful document structure that can be understood by both users and assistive technologies.

Accessibility was considered throughout development by using clear heading hierarchies, descriptive link text, alternative text for images and responsive layouts that adapt to different screen sizes. These features help ensure that content remains accessible to a wide range of users.

The User Profile, Sitemap and Content Page were validated using W3C validation tools to identify and correct HTML and CSS errors. Consistent navigation and a shared visual design were maintained across the website to improve usability and user experience.

All content included on the pages was created for educational purposes and external resources have been appropriately referenced within the References section. No misleading, offensive or inappropriate content has been included, ensuring the pages meet the standards expected for academic web publication.
